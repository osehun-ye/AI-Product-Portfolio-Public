# AI 产品经理作品集

**求职方向：AI 产品经理实习｜AI Agent · 人机协作 · 机器人产品**

关注如何从真实使用场景出发，将 AI 能力组织为可理解、可控制、可验证的产品流程。

## 产品能力

| 能力 | 工作重点 |
| --- | --- |
| 业务问题分析 | 梳理用户目标、使用场景与现有流程，明确需求优先级和验收标准 |
| AI 工作流设计 | 拆解任务，定义输入、输出、流程状态及异常处理 |
| Human-in-the-loop | 明确机器建议、人工审核、确认与接管的责任边界 |
| 原型验证 | 用原型检查流程与规则，区分模拟输出、离线验证与真实模型效果 |
| AI Coding Agent 协作 | 以任务说明和验收标准组织辅助开发，通过测试与人工复核检查结果 |

## 代表项目

### Talent Radar｜JD-first AI 人才研究原型

个人独立开展的软件项目，从岗位需求出发组织人才信息、证据与匹配判断，探索 AI 建议与人工审核协作的产品流程。

- **个人贡献：** 业务问题分析、产品定位、规则与交互设计、验收及复核；AI Coding Agent 主要执行编码与测试。
- **验证边界（案例资料截至 2026-10-26）：** 部分 JD 流程完成本地隔离验证，建议采用固定 Mock；人物关联协议完成离线验证。真实模型尚未接入，完整人工审核闭环仍待实现，影子评测尚未执行。业务实践成果不归因于后续原型。

## 个人 AI 产品原型探索

围绕具体任务，探索 AI 辅助与人工判断相结合的产品流程，重点关注：

- 从业务问题形成产品假设，界定原型范围与验证目标。
- 设计可追溯的建议与审核流程，让用户理解依据并保留决策权。
- 借助 AI Coding Agent 辅助原型实现，结合验收标准、测试和人工复核推进迭代。

**验证原则：** 固定 Mock（模拟输出）、离线验证与真实模型评测应分别判断。原型可运行不等于真实模型效果、稳定性或线上业务收益已得到验证。
